
# Personal Expense Tracker

A simple and responsive Expense Tracker Web Application built using HTML, CSS and JavaScript.

## About the Project

Personal Expense Tracker helps users manage their daily expenses without creating an account or logging in.

Users can add, edit, delete, search and filter expenses. The application also displays total expenses, monthly expenses and a monthly expense chart.

## Features

- Add new expenses
- Edit existing expenses
- Delete individual expenses
- Clear all expenses
- Search expenses
- Filter expenses by category
- Calculate total expenses
- Calculate monthly expenses
- Display total transactions
- Monthly expense chart
- Dark Mode and Light Mode
- LocalStorage data persistence
- Responsive design
- No login required

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html in your browser.
4. Start adding your expenses.

You can also use the Live Server extension in VS Code.

## Storage

This project uses browser LocalStorage to save expense data.

No external database or login system is required.

Data is stored separately in each browser on each device.
